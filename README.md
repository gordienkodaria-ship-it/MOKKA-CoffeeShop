
# MOKKA — веб-приложение кофейни

**MOKKA** — веб-приложение кофейни, разработанное на Python с использованием Django. Проект объединяет пользовательский интерфейс для просмотра ассортимента и оформления заказов с административной системой управления кофейней.

## О проекте

Цель проекта — разработка функционального веб-приложения кофейни с акцентом на современный UI/UX-дизайн, удобство использования и автоматизацию основных бизнес-процессов.

## Основные возможности

### Для пользователей
- Просмотр каталога товаров.
- Просмотр категорий и поиск товаров.
- Добавление товаров в корзину и изменение количества.
- Оформление заказов.
- Регистрация и авторизация.
- Личный кабинет.
- Просмотр публикаций блога.
- Генерация и печать чеков.

### Для администратора
- Управление товарами и категориями.
- Просмотр и обработка заказов.
- Изменение статусов заказов.
- Управление публикациями блога.
- Просмотр статистики продаж.
- Аналитика с графиками и таблицами.
- Интерактивная доска заметок с поддержкой Drag-and-Drop.

## Используемые технологии

- HTML5
- CSS3

## Дизайн

Интерфейс выполнен в премиальной editorial-стилистике с использованием тёмной цветовой палитры, золотистых акцентов и элегантной типографики.

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone ССЫЛКА_НА_РЕПОЗИТОРИЙ
   ```

2. Перейдите в папку проекта:

   ```bash
   cd CoffeeShop
   ```

3. Создайте виртуальное окружение:

   ```bash
   python -m venv venv
   ```

4. Активируйте виртуальное окружение:

   Windows PowerShell:
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

5. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

6. Выполните миграции базы данных:

   ```bash
   python manage.py migrate
   ```

7. Запустите сервер:

   ```bash
   python manage.py runserver
   ```

8. Откройте приложение в браузере:

   http://127.0.0.1:8000/

## Структура проекта

- `CoffeeShop/` — настройки Django-проекта.
- `shop/` — основное приложение кофейни.
- `static/` — статические файлы: CSS, JavaScript и изображения.
- `templates/` — HTML-шаблоны.
- `manage.py` — инструмент управления Django.
- `requirements.txt` — список зависимостей.
- `.gitignore` — список файлов, исключённых из публикации.
